Calculator

A simple and responsive Calculator Web Application developed using HTML5, CSS3, and JavaScript as part of my Web Development Internship Task 7.

Project Description

This project is a basic calculator that performs common arithmetic operations. It provides a clean interface with number and operator buttons and displays the calculation result dynamically.

How to Run
Download or clone the project.
Open the Calculator folder.
Make sure all three files are in the same folder.
Open index.html in any web browser.
Use the calculator buttons to perform calculations.
Working

The calculator uses JavaScript to manage the current number, previous number, and selected operator. When an operator is selected, the calculator stores the required values. When the equals button is pressed, JavaScript performs the selected arithmetic operation and displays the result.

The calculator also checks for division by zero and displays an appropriate message instead of performing an invalid calculation.
